# NeonSnake

A modern and besttt  snake game built by me with  smooth controls... score tracking, and COOOL gameplay.

## Description

NeonSnake is a website of snake game where the youw will control a small cute snake to collect food( box shape) 
and increase the score while avoiding wall and self collisions.... 

## Features

- Smooth movement
- Run by keyboard
- Food system
- Live score 
- Collision detection
- Game over screen
- Start and restart buttons

## How To Use / Setup

- Click on the link 
- click on the start buttom
- and then use your keyboard arrows to control it
- and eat all fruits and get bigger everytime
- avoid collisions 
- IF YOU GET LOOSE.. PLEASE CLICK RESTART BUTTON THEN ONLY GAME WILL RUN...
